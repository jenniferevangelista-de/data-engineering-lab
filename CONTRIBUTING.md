# Adicionar um exemplo
Use a próxima sequência day_NNN na trilha escolhida. Cada exemplo deve conter:
- problema e dados sintéticos;
- versões e dependências explícitas;
- comando de execução e saída esperada;
- testes de comportamento, incluindo bordas relevantes;
- comandos de teste reproduzíveis e limites de validação no README do exemplo.

Não marque integração como aprovada a partir de mock ou compilação.
Serviços externos exigem ambiente de teste, credenciais fora do Git e instruções de limpeza.
